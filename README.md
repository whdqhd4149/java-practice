# Java Backend Study

Java/Spring Boot 백엔드 개발자가 되기 위한
개인 학습 저장소입니다.

## 학습 목표
- Java 기초 문법 이해
- 객체지향 프로그래밍 학습
- Spring Boot 및 REST API 학습
- Git/GitHub 활용

## 학습 기록

### Day 01 - 변수와 자료형
- 변수 선언
- 기본 자료형
- 형변환
- 주식 매수금액 계산 실습
  
### Day 02 - 연산자와 조건문
- Day 01 복습
- 산술 연산자 및 연산 우선순위
- 정수와 실수의 나눗셈
- 비교 연산자
- 논리 연산자
- if / else if / else 조건문
- 주식 매수 가능 여부 및 매수 후 잔액 계산 실습

### Day 03 - 중첩 if문과 for문
- Day 02 조건문 복습
- 중첩 if문을 활용한 주식 매수 조건 판단
- for문 기본 구조 및 반복 실행
- 주식 매수금액 누적 합계 계산
- for문과 if문을 활용한 짝수 합계 계산
- 최대 매수 가능 수량 및 잔액 계산
- 구구단 7단 출력 실습

### Day 04 - switch문과 while문
- Day 03 복습
- switch 조건문
- case, break, default
- while 반복문
- switch와 while을 활용한 주식 거래 메뉴 실습

### Day 05 - 메서드
- 메서드 선언 및 호출
- 매개변수와 인자
- 반환 자료형(void, int)과 return
- 메서드 재사용
- 주식 매수금액 및 남은 예산 계산 실습

### Day 06 - 배열
- 배열 선언 및 초기화
- 인덱스와 length 활용
- 배열과 for문을 이용한 반복 처리
- 주식 가격 합계 계산 실습
- 주식 최고가·최저가 계산 실습
- 주식 보유자산 계산 실습
- 변수의 유효 범위(Scope) 이해

### Day 07 - Java 기초 문법 통합
- 배열과 반복문을 활용한 종목별 데이터 처리
- 매개변수와 인자의 관계
- 메서드 재사용을 통한 중복 코드 제거
- 스코프 및 누적 변수 활용
- 정수 나눗셈과 실수형 형변환
- 최댓값 비교 및 초기값 설정

**기본 실습 - 주식 계산기**
- 종목별 매수금액 및 평가금액 계산
- 종목별 평가손익 계산
- 조건문을 활용한 수익, 손익 없음, 손실 구분
- 전체 매수금액, 평가금액, 평가손익 계산

**추가 실습 - 주식 수익률 계산**
- 종목별 수익률 계산
- 메서드 재사용을 통한 전체 투자 수익률 계산
- 반복문과 조건문을 활용한 최고 수익률 종목 찾기
- 음수 수익률을 고려한 최초 비교 기준 설정
